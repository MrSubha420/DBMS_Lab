# Chapter II — SQL DDL (Data Definition Language)

## A. Introduction to DML (Data Manipulation Language) in SQL

Data Manipulation Language (DML) is a category of SQL commands used to retrieve, insert, update, and delete data stored in database tables. DML works on the records (rows) of a table without changing its structure.
